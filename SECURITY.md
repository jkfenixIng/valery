# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to [jkfenix95@hotmail.com](mailto:jkfenix95@hotmail.com). Include a clear description, affected paths or versions, reproduction steps, and impact when available.

This repository is in a local-first Phase 0. It has no public production deployment, security service-level agreement, bounty, or guaranteed response time.

## Scope

Reports about this repository's tracked source, dependencies, configuration, and local development workflow are welcome. Do not access data or systems you do not own or have explicit authorization to test.
